# 市場分析報告：AI（2026年5月）

## 1. 市場趨勢 / 新趨勢

本週的市場訊號顯示，AI 領域正從「對話式 AI」全面轉向**「代理型 AI」（Agentic AI）**，且基礎設施化趨勢明顯。以下是核心趨勢觀察：

*   **Model Context Protocol (MCP) 成為產業標準：** AWS 正式推出受管 MCP 伺服器，代表市場正朝向標準化方向發展，以解決 AI 代理（Agent）與外部工具、數據源及 API 之間的通訊障礙。這允許開發者將 AI 代理與實時雲端基礎設施無縫接軌。
*   **「無 API」遺留系統的自動化突破：** 透過 Amazon WorkSpaces 為 AI 代理提供虛擬桌面，市場出現了利用計算機視覺（Computer Vision）和輸入模擬來操作遺留系統（Legacy Systems）的新範式。這打破了過去自動化必須依賴 API 的限制，為 75% 仍在使用舊型軟體的企業提供了現代化轉型的快速通道。
*   **垂直化與專業化代理：** 雲端廠商正將 AI 能力垂直整合至特定產業（如供應鏈、醫療、招聘與客服），提供具備專業領域知識（Domain Knowledge）的解決方案，而非僅提供通用的 LLM 接口。
*   **領先模型的企業級整合：** OpenAI 的 GPT-5 系列模型進入受管雲端平台（如 Amazon Bedrock），顯示企業級 AI 的焦點已從單純的模型競爭，轉向如何在具備安全與成本控管的環境下應用最強大的模型。

## 2. 市場問題或痛點

這些技術動向反映出企業在部署 AI 時面臨的深層障礙：

*   **API 鴻溝與技術債：** 大量企業的核心流程仍鎖死在沒有 API 的舊系統或大型主機中。過去這需要極高成本的重構，現狀是自動化流程在此受阻。
*   **AI 知識滯後與安全性風險：** LLM 的訓練數據具有截斷點，無法掌握最新的雲端服務或文檔；同時，給予 AI 代理過高的 IAM 權限或寬泛的 CLI 權限，在企業環境中存在巨大的合規與安全風險。
*   **Agent 行為不可審計：** 傳統日誌難以區分「人類操作」與「AI 代理操作」，導致在發生安全事故或配置錯誤時難以溯源。
*   **Token 消耗與延遲：** 頻繁的 API 調用與長下文傳輸導致 Token 成本高昂且回應緩慢，影響生產環境的可用性。

## 3. 現有工具或解法

市場上已出現針對上述痛點的具體解法：

*   **AWS MCP Server：** 
    *   **解法：** 作為 AI 代理與 AWS 服務之間的認證代理，提供超過 15,000 個 API 的實時訪問。
    *   **亮點：** 引入「Skills」功能，由服務團隊維護最佳實踐引導；提供 `run_script` 工具，在沙箱中執行 Python 以減少 Token 消耗。
*   **Amazon WorkSpaces for AI Agents：**
    *   **解法：** 為 Agent 配置虛擬桌面，使其能像人類員工一樣點擊 UI、輸入數據。
    *   **Use Case：** 藥局系統中，Agent 透過導覽舊式病人紀錄界面來處理處方箋續藥，無需後端整合。
*   **Amazon Bedrock 受管代理與垂直解決方案：**
    *   **解法：** 提供專為供應鏈（Connect Decisions）或醫療（Connect Health）設計的代理，預整合推理能力與安全治理架構。
*   **治理工具：** 透過 CloudWatch 指標與 IAM 上下文鍵值，實現 Agent 活動的獨立審計與權限隔離。

## 4. 給產品的啟示

對於 SaaS、FinOps 或雲端管理產品，這波趨勢提供了具體的發展方向：

### 產品功能與體驗
*   **支援 MCP 協議：** Cloud Management 產品應考慮實作 MCP 伺服器節點，讓客戶的 AI 代理能直接、安全地獲取雲端資產狀態或執行 FinOps 最佳化建議。
*   **Agent 專屬工作區：** 考慮在產品中內建「Agent 專屬帳戶」或「機器人存取模式」，並提供電腦視覺友善的界面標籤，以利代理型 AI 操作。

### 權限治理與安全
*   **標籤化審計：** 在 SaaS 產品中，必須能明確區分操作是由人類還是 AI 代理發起的。應建立「Agent 操作日誌」視圖，這對 FinOps 的變更管理至關重要。
*   **沙箱化自動化：** 借鏡 `run_script` 的做法，提供安全的腳本執行環境，讓客戶的 AI 代理在產品內執行複雜的多步操作，而非頻繁透過 API 往返。

### FinOps 與成本定位
*   **Token 效率即價值：** 產品若能透過精確的上下文過濾（如預處理後的 MCP Skills）來減少客戶調用 LLM 的 Token 數量，將成為重要的核心競爭力。
*   **Agent 席位計價：** 隨著 AI 代理開始擁有虛擬桌面（如 WorkSpaces），計價模型可能需要從「按人頭」轉向「按 Agent 實例」或「自動化任務成功數」計費。

### 後續追蹤
*   **驗證重點：** 追蹤 MCP 協議在開源社群（如 LangChain, Cursor）的滲透率，以及企業對於「給 AI 一個桌面」這種模式的實際接受度（Security Review 是否能通過）。
